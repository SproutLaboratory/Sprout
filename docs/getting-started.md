# 🚀 Быстрый старт

Добро пожаловать в Sprout! Это руководство поможет вам быстро установить язык и написать первую программу.

---

## 📦 Скачать

Скачайте последнюю версию Sprout в разделе [Releases](https://github.com/SproutLaboratory/Sprout/releases).

Выберите подходящий файл для вашей системы:

| Платформа | Архитектура | Файл |
|-----------|-------------|------|
| Windows | x64 | `win_x64_Sprout.exe` |
| Linux | x64 | `linux_x64_Sprout` |

---

## 🛠️ Установка

### Windows
1. Скачайте `win_x64_Sprout.exe`
2. Создайте папку, например, `C:\Sprout`
3. Поместите `Sprout.exe` в эту папку
4. (Опционально) Добавьте папку в `PATH`, чтобы запускать из любого места

### Linux
1. Скачайте `linux_x64_Sprout`
2. Сделайте файл исполняемым:
   ```bash
   chmod +x linux_x64_Sprout
   ```
3. Поместите в папку, например, `/home/user/Sprout/`

---

## 📝 Первая программа

1. Создайте файл `hello.sprout`:

```sprout
# Моя первая программа
out "Привет, мир!"
out "Это язык Sprout!"

# Переменные
name = "Алексей"
age = 25
out "Меня зовут " + name + ", мне " + str age + " лет"

# Арифметика
x = 10
y = 20
out "x + y = " + str (x + y)
```

2. Запустите:
```bash
# Windows
Sprout.exe hello.sprout

# Linux
./Sprout hello.sprout
```

Вы увидите:
```
Привет, мир!
Это язык Sprout!
Меня зовут Алексей, мне 25 лет
x + y = 30
```

---

## 🖥️ Интерактивный режим

Запустите Sprout без параметров:

```bash
Sprout.exe
```

Теперь можно вводить код построчно:
```sprout
>> out "Привет"
Привет
>> x = 5
>> y = 3
>> out str(x + y)
8
>> exit
```
